The contenders

Five agents, five algorithms

Each agent runs a different algorithm inside its program. Minimax and Alpha-Beta compute the same values with very different amounts of work, so there are four distinct decision rules, and each trades speed for foresight differently. Pick one in Play, pit two against each other in the Arena, or measure them in the Lab.
